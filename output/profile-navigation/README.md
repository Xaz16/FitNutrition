# Глобальная навигация и профиль

Обновление от 30.10.2026. Общий sidebar доступен на семи внутренних экранах, на узкой ширине открывается закреплённой кнопкой «Меню». До сохранения первичного профиля расчётные разделы заблокированы.

Мой профиль открывает карточку, а не визард. Диалог изменяет одно поле через PATCH /api/profile. Возраст вычисляется на сервере по birth_date при чтении и генерации. Старые профили без даты сохраняют прежний возраст; вымышленная дата им не назначается. Изменение расчётных параметров требует пересоставить план.

Проверки: 28 unittest; браузерные сценарии регистрации, результата, закупок и нового профиля пройдены в Chrome 156.0.8078.79. Семь экранов проверены на 360/768/1440 px, горизонтальное переполнение не обнаружено. Отдельно проверены сохранение и отмена поля, сохранность остальных данных, повторное чтение даты, вычисление возраста и мобильное меню. JSON результатов рядом. Узкая ширина настольного браузера не заменяет проверку на физическом телефоне.

Скриншоты сняты на отдельной временной базе и демоаккаунте. Даты рождения и имя в них являются тестовыми данными. Существующие пользовательские профили не перезаписывались.
