# Архитектурные материалы ЛР2

ER-модель: er_domain.drawio и er_domain.svg. Физические таблицы указаны рядом с предметными названиями. Пунктир состава блюда обозначает ссылки в JSON без SQL FK.

Activity: activity_registration и activity_generation, форматы drawio и SVG. Файлы drawio открываются в diagrams.net, блоки и связи редактируются отдельно. SVG подходят для вставки в отчёт.

DOT и JSON содержат текстовые описания графов. build_lab2_diagrams.cjs является копией генератора; запускать основной файл scripts/build_lab2_diagrams.cjs из репозитория. Нужны Node.js, @viz-js/viz и sharp; путь к пакетам задаётся через ARTIFACT_NODE_MODULES.

API описан по текущему server.py. Примеры ответов сокращены, условные числа не являются результатами нового тестирования. Новые ADR имеют номера 007-010; ADR-006 сохранён в основном отчёте.

В этой итерации изменялись только документы и схемы, тесты приложения не запускались.
