# Протокол проверки прототипа

Дата: 25.10.2026. Среда: Windows 11 Pro, версия 10.0.26200; Python 3.12.14; Google Chrome 155.0.8059.85. Браузер управляется Playwright, приложение запущено на 127.0.0.1. Тестовые аккаунты и временные базы не содержат пользовательских данных.

## Расчёты и HTTP API

Команда: `python -m unittest discover -s prototype/tests -v` из корня репозитория после установки `prototype/requirements.txt`.

Результат: 16 тестов пройдены, ошибок и пропусков нет. Проверены 9 доменных и 7 API-сценариев. API-тесты поднимают отдельный сервер на свободном порту и используют временную SQLite.

| Группа | Проверка | Результат |
|---|---|---|
| Нормы | Пример ЛР1: 2345 ккал, 176/78/235 г БЖУ | Пройдено |
| Валидация | 6/32 дня, дробный период, нулевой бюджет, NaN | Отклонены |

## Границы результатов

Нагрузочные условия NFR-02 и NFR-04 не воспроизводились; 24-часовое обновление реальных цен NFR-03 не проверялось. Проверка примера нормы — проверка арифметики, а не медицинской пригодности. Тестовый каталог не подтверждает качество рецептов и рыночную экономию. Полная матрица NFR-05 остаётся незавершённой до Firefox и Safari.
