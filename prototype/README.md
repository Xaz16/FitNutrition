# Fit Nutrition Supply

Запускаемый прототип ЛР2. Основная ЦА — взрослые с интересом к снижению веса. Пилотный город — Ижевск. Цены пяти сетей, пищевая ценность и рецепты — учебные данные, а не подключённые каталоги магазинов.

## Быстрый запуск Windows

Нужен Python 3.10 или новее; основные испытания выполнены на Python 3.12.14, запуск дополнительно проверен на установленном Python 3.10. В PowerShell из папки `prototype`:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start.ps1
```

.cmd для запуска двойным щелчком: Start.cmd. Скрипт создаёт локальную `.venv`, устанавливает единственную зависимость bcrypt и открывает браузер. Интернет нужен только при первой установке зависимости. Приложение открывается по адресу http://127.0.0.1:8765. Остановка — Ctrl+C в окне сервера.

Если окружение уже создано, но установка прервалась, выполните `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` и повторите запуск.

## Запуск вручную

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py --open
```

Linux/macOS: `python3 -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt`, `.venv/bin/python server.py --open`.

## Демонстрация

1. Откройте демоверсию либо зарегистрируйте тестовый аккаунт. Демо создаёт отдельную учётную запись без пароля.
2. Пройдите обязательный профиль с датой рождения: параметры, активность и цель, ограничения и сводку. Третий шаг можно пропустить. Сохраните профиль и на дашборде нажмите «Настройте ваш план».
3. После генерации откроется результат по дням с ценами блюд и бюджетом корзины. Нажмите «Заменить»: варианты показывают калории и разницу всей закупки. «Выбрать» применяет одну замену без перезагрузки. «Сохранить план» сохраняет статус; последующая замена возвращает черновик.
4. В списке введите запас любого продукта и отметьте купленную позицию.
5. Откройте корзины. Посмотрите полную сумму, фасовки, остатки и бюджет. Неполная сеть не победит полную.
6. Нажмите «Показать сбой источника»: появится ошибка, прежние предложения и сумма останутся.
7. Перезагрузите страницу: профиль и план сохранены. Незавершённый онбординг тоже сохраняет черновик. Чтобы показать ошибку валидации, в плане задайте 6 дней; чтобы показать нехватку рецептов, максимум 5 минут готовки.

Профиль хранится отдельно от конкретного плана. В онбординге вводится дата рождения, возраст 14-90 рассчитывается сервером; автоматическая генерация текущего прототипа доступна с 18 лет. При изменении параметров предыдущий план остаётся в базе, но требуется его пересоставить. Другие аллергии нужно указать точными названиями продуктов каталога; незнакомые значения не игнорируются.

Схемы нового потока: docs/lab2/diagrams/entry_flow.drawio и onboarding_screens.drawio, также доступны SVG. Браузерный тест: prototype/tests/onboarding.cjs; используйте TEST_URL для выбранного порта.

Замена блюда: docs/lab2/diagrams/activity_alternative.drawio и SVG. Описание фильтров и разницы полной корзины: docs/lab2/replacement_logic.md. Браузерный тест: prototype/tests/result.cjs. Цены блюд являются оценкой ингредиентов; корзина считает целые упаковки с учётом запасов.

## Навигация и изменение профиля

Левое меню общее для дашборда, профиля, настроек плана, результата, меню, списка и корзин. На узком экране закреплена кнопка «Меню». До завершения первичного профиля остальные разделы заблокированы.

После онбординга «Мой профиль» открывает карточку. Кнопка «Изменить» у поля открывает отдельный диалог. PATCH /api/profile принимает ровно одно поле и объединяет его с текущими данными на сервере. Отмена не записывает изменения. Возраст вычисляется по birth_date при чтении и генерации; присланный age не заменяет дату. Старые профили без даты продолжают использовать сохранённый возраст, пока пользователь не укажет дату. Столбцы SQLite менять не требуется, профиль хранится в JSON.

Проверка: 28 тестов unittest, браузерные сценарии onboarding.cjs, result.cjs, browser.cjs и profile-navigation.cjs. Новый сценарий проверяет семь экранов на 360/768/1440 px, редактирование одного поля, отмену, дату и блокировку устаревшего плана. Скриншоты и результаты: output/profile-navigation/.

## Хранение и ограничения

SQLite создаётся автоматически в `data/fitnutrition.sqlite3`. Каталог загружается один раз. Эта папка и `.venv` исключены из Git. При переносе на другой компьютер база не переносится автоматически: созданные аккаунты и планы остаются на запущенном сервере. Доступ с других устройств и HTTPS требуют отдельного развёртывания; текущий сервер намеренно слушает только loopback.

Семейные профили, реальные цены, ручное сопоставление товаров, корзина из двух сетей, ИИ-анализ, шаблоны, фактические расходы, оформление и оплата пока не реализованы. БЖУ показывается фактическое по учебным ингредиентам, точное попадание в целевое соотношение не гарантируется. Полная матрица требований — в отчёте ЛР2.

## Проверки

Из корня репозитория, используя Python окружения прототипа:

```powershell
prototype\.venv\Scripts\python.exe -m unittest discover -s prototype/tests -v
```

Браузерный тест дополнительно требует Node.js, Playwright и установленный Google Chrome. При доступном npm-пакете playwright: `node prototype/tests/browser.cjs`. Он использует уже запущенный сервер; нестандартный адрес передаётся переменной TEST_URL. Для пакетного размещения Playwright можно задать PLAYWRIGHT_MODULE абсолютным путём. Артефакты проверки сохраняются только в tmp/lab2/browser-qa.
