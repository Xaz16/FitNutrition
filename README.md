# Fit Nutrition Supply

Учебный проект по дисциплине «Проектирование и конструирование ПО».
Команда: Фазлыев А. А. и Чипига А. А., группа Б23-191-2.

Основная аудитория — взрослые люди, заинтересованные в снижении веса. Город пилота — Ижевск. Бюджет и время приготовления учитываются как ограничения пользователя.

Windows: установите Python 3.10+, откройте PowerShell в `prototype` и выполните `powershell -ExecutionPolicy Bypass -File .\Start.ps1`. Адрес: http://127.0.0.1:8765. Сервис работает с SQLite; единственная внешняя зависимость приложения — bcrypt. Интернет нужен для её первой установки.

Работают регистрация с именем, обязательный профиль из трёх шагов и сводки, дашборд, отдельный план на 7-31 день, замена блюда, список, запасы и пять учебных корзин. Левое меню общее для внутренних экранов. После онбординга профиль открывается карточкой с редактированием отдельных полей. Возраст рассчитывается по дате рождения. Профиль сохраняется отдельно; черновик онбординга переживает возврат и перезагрузку. Цены и пищевая ценность демонстрационные. Реальных интеграций магазинов, внешнего ИИ, оплаты и заказа пока нет.

## Воспроизводимость

Тесты: `prototype\.venv\Scripts\python.exe -m unittest discover -s prototype/tests -v` из корня репозитория. Пройдены 28 теста; браузерные проверки основного пути, онбординга и результата с заменой. Предварительная разница цены проверена против фактической корзины. Firefox и Safari ещё не проверены.

Схемы можно редактировать в draw.io без генератора. Для генерации Graphviz-схем: установить Node.js и зависимости из `tools/package.json`, выполнить `node scripts/build_lab2_diagrams.cjs`. Для wireframe: `python scripts/build_lab2_wireframes.py`. Для сборки Word нужны python-docx и Pillow, затем `python scripts/build_lab_reports.py`; сохранённый шаблон титульника используется при наличии, иначе создаётся резервный титульник. PDF получают экспортом Word/LibreOffice; основной текст A4, крупные схемы — A3.

SQLite, аккаунты, виртуальное окружение и временные результаты не включаются в Git. Архитектура, код и история лабораторных ведутся в одном репозитории.
