# Fit Nutrition Supply

Материалы лабораторной работы 1 по концепции и спецификации проекта.

Авторы: Чипига Алексей Александрович и Фазлыев А. А.

## Материалы для сдачи

- `output/Fit_Nutrition_Supply_Lab1.pdf` — оформленный отчёт.
- `output/Fit_Nutrition_Supply_pitch_final.pptx` — презентация из пяти слайдов с заметками для выступления.
- `docs/lab1.md` — редактируемый исходник отчёта.
- `docs/defense.md` — подготовка к защите и проверка полноты по ТЗ.
- `sources/` — исходная презентация и предоставленные скриншоты задания.

Бесплатная база включает планирование меню, закупок и углублённую аналитику предпочтений. Партнёрские предложения рассматриваются как будущая модель дохода; договорённостей ещё нет.

Спецификация: шесть аналогов по десяти характеристикам, 16 User Stories, 21 FR, 5 NFR, MoSCoW, пять рисков и анализ работы с ИИ. Программная реализация приложения и фактические испытания критериев приёмки не заявляются.

Весь курс следует продолжать в этом репозитории, сохраняя историю изменений. Проверка истории: `git log --oneline`. Репозиторий локальный; публикация на GitHub не выполнялась.

Перед сдачей требуется подтвердить согласование идеи с преподавателем и сверить группу обоих участников. Группа Б23-191-2 взята из исходной презентации. Время выступления нужно проверить репетицией.
