# Fit Nutrition Supply

Учебный проект по дисциплине «Проектирование и конструирование ПО».
Команда: Фазлыев А. А. и Чипига А. А., группа Б23-191-2.

Основная аудитория — взрослые люди, заинтересованные в снижении веса. Город пилота — Ижевск. Бюджет и время приготовления учитываются как ограничения пользователя.

## Лабораторная работа 2

- [Запуск и демонстрация прототипа](prototype/README.md).
- [Архитектурный документ](docs/lab2/architecture.md), [пять ADR](docs/lab2/adr), [протокол проверок](docs/lab2/test_results.md).
- [Диаграммы и исходники](docs/lab2/diagrams): структура, use case, три activity, ER, wireframe.
- [Полный отчёт Word](output/lab2/Fit_Nutrition_Supply_LR2.docx) и [PDF](output/lab2/Fit_Nutrition_Supply_LR2.pdf).

Windows: установите Python 3.12+, откройте PowerShell в `prototype` и выполните `powershell -ExecutionPolicy Bypass -File .\Start.ps1`. Адрес: http://127.0.0.1:8765. Сервис работает с SQLite; единственная внешняя зависимость приложения — bcrypt. Интернет нужен для её первой установки.

Работают регистрация, меню на 7–31 день, подтверждаемая замена блюда, суммарный список, домашние запасы, целые упаковки, сравнение пяти учебных корзин и проверка бюджета. Цены, пищевая ценность и рецепты — демонстрационные данные. Реальных интеграций магазинов, внешнего ИИ, оплаты и заказа пока нет. Полная матрица покрытия FR/NFR включена в отчёт.

## Воспроизводимость

Тесты: `prototype\.venv\Scripts\python.exe -m unittest discover -s prototype/tests -v` из корня репозитория. Браузерный тест описан в README прототипа. Выполненный прогон: 16 тестов; Chrome 155.0.8059.85 на ширинах 360/768/1920, 12 сочетаний экранов без горизонтальной прокрутки. Firefox и Safari ещё не проверены.

Схемы можно редактировать в draw.io без генератора. Для генерации Graphviz-схем: установить Node.js и зависимости из `tools/package.json`, выполнить `node scripts/build_lab2_diagrams.cjs`. Для wireframe: `python scripts/build_lab2_wireframes.py`. Для сборки Word нужны python-docx и Pillow, затем `python scripts/build_lab_reports.py`; сохранённый шаблон титульника используется при наличии, иначе создаётся резервный титульник. PDF получают экспортом Word/LibreOffice; основной текст A4, крупные схемы — A3.

SQLite, аккаунты, виртуальное окружение и временные результаты не включаются в Git. Архитектура, код и история лабораторных ведутся в одном репозитории.
